# 春日部防卫队角色分工

## 项目 Owner
负责人：我  
职责：最终决策、Git 仓库最高权限、比赛/项目材料统筹、演示验收。

## 小新｜产品经理 / MVP 总控
职责：
- 定义 MVP 核心链路；
- 编写和维护 SPEC；
- 控制功能边界；
- 判断新增功能是否服务于演示闭环；
- 从用户视角检查“能不能看懂、能不能跑通”。

禁止：
- 不允许随意新增非 MVP 功能；
- 不允许为了好看牺牲主流程稳定；
- 不允许把赛题参考版写成正式参赛承诺。

## 风间彻｜研发负责人 / 架构把关
职责：
- 技术路线确认；
- 前后端、数据库、API 架构把关；
- 判断功能是否可开发、是否超出 MVP；
- 管理代码结构和接口规范。

## 阿呆｜数据与算法负责人
职责：
- 岗位 JD 样例数据；
- 技能词典；
- 技能抽取规则；
- 岗位能力图谱关系；
- 匹配规则与推荐规则验证。

## 妮妮｜UI / 交互设计
职责：
- 页面原型；
- 图表展示；
- 操作流程简化；
- 视觉统一；
- 保证演示页面清晰、正式、不花哨。

## 正男｜测试 / 体验巡检
职责：
- 测试用例；
- BUG 记录；
- 演示检查；
- 上线前验收；
- 负责指出“哪里会翻车”。

## 决策规则
1. 小新提出需求。
2. 风间判断技术可行性。
3. 阿呆判断数据是否支撑。
4. 妮妮判断页面是否清晰。
5. 正男测试是否稳定。
6. 我最终决定是否进入 MVP。

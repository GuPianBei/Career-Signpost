# 职向标｜项目总说明

## 1. 项目定位
职向标是一个参考 XH-202621 赛题方向的岗位能力图谱与人岗匹配诊断网站。

本项目不以严格参赛为当前目标，而是以赛题为参考，训练以下能力：
- 赛题理解与需求拆解；
- MVP 范围控制；
- 数据建模与接口设计；
- AI API 调用与兜底；
- 图谱可视化与演示闭环；
- 项目文档和 Git 管理。

## 2. 当前版本目标
当前版本为“赛题参考版 MVP”，只要求核心环节能跑通，不追求比赛级完整指标。

## 3. 核心闭环
岗位 JD 导入 → 技能抽取 → 岗位能力图谱 → 简历/学生能力输入 → 人岗匹配 → 能力缺口 → 学习路径与改进建议 → 可视化展示。

## 4. 非目标
当前版本暂不追求：
- ≥100 条 JD 正式测试；
- JD / 简历 / 匹配准确率 ≥90%；
- 复杂新岗位自动发现；
- 完整 PDF/Word 简历解析；
- 企业级部署；
- 大模型训练。

## 5. 项目 Owner
项目最高负责人：用户本人。  
Git 仓库最高权限、最终决策权、范围裁剪权均由项目 Owner 保留。

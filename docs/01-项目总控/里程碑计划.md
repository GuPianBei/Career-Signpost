# 里程碑计划｜赛题参考版

## M0：项目整理与范围锁定
目标：确定目录结构、MVP 范围、角色分工、Git 规则。  
完成标准：
- 文件夹结构整理完成；
- MVP 范围说明完成；
- 角色分工完成；
- Git 仓库初始化。

负责人：小新 + 项目 Owner

## M1：数据模板与数据库基础
目标：准备岗位 JD、学生/简历能力、课程资源、实训任务模板。  
完成标准：
- 数据模板可填写；
- 数据库表草案完成；
- 演示数据字段确定。

负责人：阿呆 + 风间彻

## M2：后端基础接口
目标：完成学生/能力输入、岗位导入、技能标签、推荐结果的基础接口。  
完成标准：
- 基础 CRUD 可用；
- 接口返回格式统一；
- 错误提示明确。

负责人：风间彻

## M3：前端基础页面
目标：完成 5 个 MVP 页面框架。  
完成标准：
- 页面可访问；
- 表单可填写；
- 表格可展示；
- 图表区域可显示假数据或真实数据。

负责人：妮妮 + 风间彻

## M4：核心闭环跑通
目标：岗位 JD → 技能抽取 → 图谱 → 匹配 → 建议报告。  
完成标准：
- 用 10-30 条演示 JD 可跑通；
- 可以生成能力缺口；
- 可以输出学习路径建议；
- AI 失败时有模板兜底。

负责人：小新 + 阿呆 + 风间彻

## M5：测试与演示
目标：完成 3-5 分钟演示链路。  
完成标准：
- 正男完成测试记录；
- 主流程不卡死、不白屏；
- 有演示脚本；
- 有截图和说明材料。

负责人：正男 + 小新

## M6：扩展判断
目标：判断是否转为正式参赛版。  
完成标准：
- 若参赛：补齐 100 条 JD、简历解析、准确率测试、新岗位发现；
- 若不参赛：继续作为作品集项目和学习项目维护。

负责人：项目 Owner

# 3-5分钟演示脚本｜赛题参考版

## 1. 开场
本项目名为“职向标”，是一个参考岗位能力图谱赛题方向设计的岗位能力分析与人岗匹配诊断系统。当前版本是赛题参考版 MVP，重点验证核心链路是否能跑通。

## 2. 展示岗位数据
这里导入了若干新一代信息技术方向的岗位 JD，例如 Java 后端、AI 应用开发、数据分析等。

## 3. 技能抽取
系统会从岗位描述中抽取技能关键词，并进行归一化，例如 Spring Boot、MySQL、Redis、Vue、Python 等。

## 4. 岗位能力图谱
抽取后的技能会与岗位形成关系，用图谱或图表展示岗位需要哪些能力。

## 5. 输入学生能力
接下来输入一个学生的已掌握技能和项目经历，模拟简历结构化信息。

## 6. 人岗匹配
系统对比学生技能和目标岗位能力要求，计算匹配分，并输出已匹配技能和缺失技能。

## 7. 学习路径建议
根据缺失技能，系统推荐课程和实训任务，并生成改进建议报告。

## 8. 结尾
当前版本重点完成 MVP 闭环。若后续转为正式参赛版，将继续补齐 100 条 JD 测试、简历解析、动态岗位发现和准确率评测。

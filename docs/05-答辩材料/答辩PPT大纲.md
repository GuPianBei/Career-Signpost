# 答辩PPT大纲｜赛题参考版

## 1. 项目标题
职向标：岗位能力图谱与人岗匹配诊断系统

## 2. 项目背景
数字经济发展导致岗位技能变化加快，学生和求职者难以及时了解岗位能力要求。

## 3. 需求痛点
- 岗位技能要求不清晰；
- 学生能力与岗位要求难匹配；
- 学习路径缺少针对性；
- 岗位能力变化难追踪。

## 4. 项目定位
参考 XH-202621 赛题方向，构建一个赛题参考版 MVP。

## 5. 核心闭环
JD 导入 → 技能抽取 → 图谱生成 → 能力输入 → 匹配诊断 → 学习建议。

## 6. 系统功能
- 岗位 JD 管理；
- 技能抽取；
- 岗位能力图谱；
- 学生能力输入；
- 人岗匹配；
- 能力缺口；
- 学习路径推荐；
- 建议报告。

## 7. 技术路线
Vue3 + Spring Boot + MySQL + Python 数据处理 + 国内 AI API。

## 8. MVP 演示
用一个学生样例和一个目标岗位演示完整流程。

## 9. 当前边界
本版本为赛题参考版，不承诺完整比赛硬性指标。

## 10. 后续扩展
- 100 条 JD 测试；
- 简历 PDF/Word 解析；
- 新岗位发现；
- 能力动态更新；
- 准确率评测；
- Docker 部署。

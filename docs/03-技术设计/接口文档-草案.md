# 接口文档草案

## 统一返回格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": "2026-06-11 21:00:00"
}
```

## 岗位模块

### POST /api/jobs/import
用途：导入岗位 JD 样例。

### GET /api/jobs
用途：查询岗位列表。

### POST /api/jobs/extract-skills
用途：抽取岗位技能标签。

## 学生能力模块

### POST /api/students
用途：新增学生能力画像。

### GET /api/students/{id}
用途：查询学生能力画像。

## 匹配推荐模块

### POST /api/match/generate
用途：生成岗位匹配结果。

输入：
- studentId
- targetJobDirection

输出：
- matchScore
- matchedSkills
- missingSkills
- recommendedCourses
- recommendedTasks

## 图谱模块

### GET /api/graph/job-skill
用途：查询岗位—技能图谱数据。

## AI 模块

### POST /api/ai/advice
用途：生成改进建议。

注意：前端不直接调用第三方 AI API，由后端统一转发。

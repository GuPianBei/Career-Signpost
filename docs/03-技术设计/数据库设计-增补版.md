# 数据库设计｜赛题参考版

## 1. job_info 岗位信息表
存储岗位 JD 原始数据。

关键字段：
- id
- job_title
- job_direction
- company_name
- city
- publish_time
- job_description
- source_platform
- batch_no
- created_at

## 2. skill_tag 技能标签表
存储归一化技能。

关键字段：
- id
- skill_name
- normalized_name
- skill_type
- alias_names

## 3. job_skill_relation 岗位技能关系表
记录岗位和技能之间的关系。

关键字段：
- id
- job_id
- skill_id
- weight
- evidence_text

## 4. student_profile 学生能力表
当前 MVP 可用学生能力表代替复杂简历解析。

关键字段：
- id
- student_code
- major
- grade
- skills
- project_experience
- target_job_direction

## 5. course_resource 课程资源表
存储课程推荐数据。

关键字段：
- id
- course_name
- skill_tags
- suitable_level
- recommend_reason

## 6. training_task 实训任务表
存储实训任务推荐数据。

关键字段：
- id
- task_name
- required_skills
- difficulty_level
- expected_output

## 7. recommendation_record 推荐记录表
保存每次匹配和推荐结果。

关键字段：
- id
- student_id
- target_job_direction
- matched_skills
- missing_skills
- job_match_score
- recommended_courses
- recommended_tasks
- advice_report

## 8. optional：ability_change_record 能力变化记录表
用于后续模拟“既有岗位能力动态更新”。

关键字段：
- id
- job_direction
- old_batch_no
- new_batch_no
- added_skills
- removed_skills
- changed_skills
- evidence_summary

# 技术路线说明｜赛题参考版

## 1. 产品形态
网站。

## 2. 推荐技术栈
### 前端
Vue 3 + Vite + Element Plus + ECharts

### 后端
Spring Boot 3 + Java 17 + MyBatis-Plus

### 数据库
MySQL 8

### 数据处理
Python + pandas + openpyxl

### AI 能力
优先国内开放云端 API，尽量同一厂商。  
当前可选：
- 讯飞星火 API；
- 通义千问 API；
- 豆包 API；
- 本地 Ollama 作为后续备选。

## 3. AI 使用边界
AI 可用于：
- JD 技能抽取辅助；
- 岗位总结；
- 学习建议生成；
- 报告润色。

AI 不可用于：
- 作为唯一匹配依据；
- 虚构学生经历；
- 虚构岗位要求；
- 替代规则计算。

## 4. MVP 技术验证重点
- JD 数据能导入；
- 技能标签能生成；
- 匹配分能计算；
- 缺失技能能解释；
- 推荐结果能展示；
- AI 失败时系统不崩。

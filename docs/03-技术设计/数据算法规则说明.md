# 数据与算法规则说明

## 1. 技能抽取规则
MVP 阶段采用“技能词典匹配 + 别名归一化 + 证据句定位”的规则方案。

处理流程：
1. 读取岗位描述。
2. 用 `技能词典.csv` 中的 `抽取关键词` 和 `别名` 做匹配。
3. 命中别名时归一到 `标准技能名`。
4. 将包含命中技能的岗位描述片段保存为 `证据句`。
5. AI 可辅助补充候选技能，但必须人工确认后进入词典。

## 2. 技能权重规则
第一版权重保持简单可解释：
- 核心技能：1.0，岗位描述中出现“熟悉、掌握、负责、要求”等强表达。
- 重要技能：0.8，岗位描述中出现“了解、参与、配合”等中等表达。
- 加分技能：0.5，岗位描述中出现“优先、加分、了解即可”等弱表达。

若没有自动识别强弱表达，默认权重为 0.8。

## 3. 人岗匹配分
匹配分由规则计算，不由 AI 直接生成。

```text
技能覆盖分 = 已掌握岗位技能权重之和 / 岗位技能总权重 * 70
项目经验分 = 项目技术栈命中岗位核心技能数量 / 岗位核心技能数量 * 20
方向兴趣分 = 学生兴趣方向与目标岗位方向一致时 10 分，否则 5 分
总分 = 技能覆盖分 + 项目经验分 + 方向兴趣分
```

总分上限 100 分，低于 60 为“基础待补齐”，60-79 为“具备入门基础”，80 分以上为“匹配度较高”。

## 4. 能力缺口排序
缺失技能优先级按以下顺序排序：
1. 岗位核心技能优先。
2. 多个岗位共同出现的技能优先。
3. 有课程和实训任务可补齐的技能优先。
4. 与学生目标岗位方向直接相关的技能优先。

## 5. 推荐规则
课程推荐解决“学什么”，实训任务推荐解决“做什么证明我会”。

推荐逻辑：
1. 根据缺失技能匹配 `课程资源模板.csv` 的 `对应技能`。
2. 根据缺失技能和岗位方向匹配 `实训任务模板.csv` 的 `训练技能` 和 `岗位方向`。
3. 优先推荐入门课程，再推荐项目任务。
4. 每个诊断报告至少输出 2 门课程和 1 个实训任务。

## 6. AI 兜底与幻觉防控
AI 只负责把结构化结果组织成自然语言报告，不参与分数计算。

禁止：
- 虚构学生经历。
- 虚构岗位要求。
- 虚构课程、证书、奖项、实习。
- 生成无法回溯到 `证据句` 或规则来源的技能结论。

AI 不可用时，使用模板：

```text
你的目标岗位是 {target_job}，当前匹配分为 {score}。
已匹配技能：{matched_skills}。
优先补齐技能：{missing_skills}。
建议先学习：{recommended_courses}。
建议完成实训：{recommended_tasks}。
以上建议基于岗位 JD 证据句和系统规则计算生成。
```

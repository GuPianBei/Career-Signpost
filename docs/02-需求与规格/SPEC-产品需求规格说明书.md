# SPEC｜职向标产品需求规格说明书（赛题参考版）

## 1. 项目定位
职向标是一个参考 XH-202621 赛题方向的岗位能力图谱与人岗匹配诊断网站。

当前阶段不严格实现正式比赛的所有硬性指标，而是优先完成一个可运行、可演示、可扩展的 MVP。

## 2. 目标用户
- 计算机类专业学生；
- 想了解岗位能力要求的学习者；
- 指导老师；
- 项目评审者；
- 后续可扩展为就业指导人员。

## 3. 核心需求
用户希望知道：
1. 某类岗位需要哪些能力；
2. 自己当前能力与目标岗位差距在哪里；
3. 应该优先补哪些技能；
4. 可以通过哪些课程或实训任务补齐；
5. 系统能否用图谱和报告清晰展示结果。

## 4. MVP 核心链路
岗位 JD 导入 → 技能关键词抽取 → 岗位能力图谱 → 学生/简历能力输入 → 人岗匹配 → 能力缺口 → 学习路径与改进建议 → 可视化展示。

## 5. MVP 必须完成
1. 岗位 JD 样例导入；
2. 技能关键词抽取；
3. 技能标签归一化；
4. 岗位—技能关系生成；
5. 学生能力或简历结构化信息录入；
6. 人岗匹配分计算；
7. 能力缺口输出；
8. 课程/实训任务推荐；
9. AI 或模板生成改进建议；
10. 图表和图谱展示。

## 6. MVP 暂不完成
1. 不强制 ≥100 条 JD；
2. 不承诺 JD / 简历 / 匹配准确率 ≥90%；
3. 不做复杂 PDF/Word 简历解析；
4. 不做真实招聘平台自动爬虫；
5. 不做自动投递；
6. 不训练大模型；
7. 不做 APP / 小程序；
8. 不做复杂登录注册。

## 7. 页面清单
### 7.1 首页
展示项目定位、核心闭环、演示入口。

### 7.2 岗位 JD 与技能图谱页
支持导入或查看岗位 JD，展示抽取出的技能标签和岗位—技能关系。

### 7.3 学生能力 / 简历信息页
支持录入技能、项目经历、目标岗位方向。

### 7.4 人岗匹配与能力缺口页
展示匹配分、已掌握技能、缺失技能、证据说明。

### 7.5 学习路径与报告页
展示推荐课程、推荐实训任务、AI / 模板生成的改进建议。

## 8. 技术验证策略
- 优先使用开放云端 API；
- 优先使用国内 API；
- 尽量使用同一厂商 API；
- AI 只做文本生成和辅助抽取，不作为唯一决策来源；
- 核心匹配必须保留规则计算；
- AI 不可用时使用模板兜底。

## 9. 验收标准
- 3-5 分钟能完整演示一条闭环；
- 岗位数据为空时有提示；
- AI 服务失败时主流程不崩；
- 前端不白屏；
- 匹配结果能解释来源；
- 文档不承诺未实现的比赛硬指标。

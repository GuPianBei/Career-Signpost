# 竞品差异分析

## 1. 对标对象边界
本项目不直接对标 BOSS 直聘、智联招聘、前程无忧等招聘平台的核心交易能力。招聘平台解决的是“岗位发现、企业沟通、简历投递、招聘转化”问题；职向标解决的是“投递前能力诊断、岗位能力拆解、学习路径规划”问题。

## 2. 与 BOSS 直聘的差异
| 对比项 | BOSS直聘 | 职向标 |
|---|---|---|
| 核心目标 | 找工作、沟通、投递 | 看懂岗位要求、诊断能力差距 |
| 主要用户动作 | 搜职位、聊 Boss、投简历 | 导入 JD、抽取技能、生成差距报告 |
| 核心资源 | 企业岗位、招聘双方连接 | 岗位能力图谱、学习路径、项目任务 |
| 结果导向 | 面试机会与招聘转化 | 能力补齐与求职准备 |
| 适合人群 | 已进入求职阶段的人 | 大一到大三、能力尚未成型的学生 |

一句话定位：BOSS 直聘解决“我要去哪投”，职向标解决“我现在差什么、怎么补到能投”。

## 3. 与简历工具的差异
超级简历、职徒简历等工具重点优化简历表达，而职向标重点从岗位 JD 反推能力要求，并把能力缺口转化为课程和项目任务。简历优化只是本项目后续报告的一部分，不是项目主功能。

## 4. 与学校就业平台的差异
学校就业平台偏岗位发布和就业手续管理，通常缺少细粒度岗位技能图谱、动态能力变化分析和个性化学习路径建议。职向标更适合作为学院人才培养、课程建设和学生求职准备的辅助工具。

## 5. 与普通课程推荐系统的差异
普通课程推荐系统从课程出发，职向标从岗位 JD 出发。先识别岗位真实能力要求，再根据学生缺口推荐课程和实训任务。

## 6. 不可宣称的优势
1. 不宣称岗位数量超过招聘平台。
2. 不宣称替代 BOSS 直聘。
3. 不宣称可以直接带来 offer。
4. 不宣称 AI 结果完全准确。
5. 不宣称完成企业级招聘闭环。

## 7. 可宣称的优势
1. 将岗位 JD 转化为可理解的技能节点。
2. 将岗位要求和学生能力进行可解释匹配。
3. 输出能力缺口、证据句、课程和项目任务。
4. 适合作为低年级学生求职前的能力诊断工具。
5. 可作为学院课程建设和实训任务设计的参考系统。

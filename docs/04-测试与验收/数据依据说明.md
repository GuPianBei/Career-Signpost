# 演示数据依据说明

## 1. 数据性质
本目录下的 CSV 已升级为“赛题参考版 MVP 真实岗位采集数据”。岗位名称、城市、岗位 URL、发布时间、职责文本和要求文本来自腾讯招聘公开岗位接口；课程、任务、学生样例和推荐记录根据真实岗位要求派生，用于验证“JD -> 技能抽取 -> 图谱 -> 匹配 -> 推荐”的演示闭环。

`公司/来源` 现在以腾讯及腾讯相关招聘主体为准，例如腾讯、腾讯云、腾讯云智研发子公司。岗位 URL、发布时间和岗位文本可通过腾讯招聘岗位详情接口核验。注意：为降低版权和展示风险，项目演示页建议展示岗位 URL、采集时间、结构化技能和短证据句；完整岗位文本仅作为内部数据核对字段使用。

## 2. 主要依据
- 赛题原文：`docs/00-赛事通知/XH-202621_多源异构数据驱动岗位和能力图谱构建与动态演化分析研究.pdf`
- O*NET Software Developers：软件开发岗位涉及需求分析、软件开发、测试、数据库等活动。
- O*NET Web Developers：Web 开发岗位涉及网站、Web 应用、交互界面、数据库和浏览器兼容性。
- O*NET Software Quality Assurance Analysts and Testers：软件测试岗位涉及测试执行、缺陷记录、测试用例和回归测试。
- O*NET Data Scientists：数据岗位涉及大数据处理、数据挖掘、机器学习、自然语言处理、可视化和报告。
- O*NET Computer Systems Engineers/Architects：系统工程岗位涉及系统集成、部署、网络、安全、系统运行和技术支持。
- 技术依据：Spring Boot、Vue、ECharts、FastAPI、pandas、Docker、Prometheus、OWASP、MQTT、Spark、Hive、scikit-learn、PyTorch、TensorFlow 等官方文档。
- 真实岗位来源：腾讯招聘公开岗位接口。
- 采集时间：2026-06-12 11:52:03 +08:00。

## 3. 使用原则
1. 每条岗位都保留 `依据来源` 和 `依据URL`。
2. 每条岗位的 `证据句` 来自本条岗位描述本身，便于演示可解释抽取。
3. 技能词典中保存标准技能名、别名、技能类型、岗位方向、难度层级和来源。
4. AI 只能基于这些字段生成报告，不允许虚构岗位、课程、项目、证书或经历。
5. 若后续转为正式参赛版，需要替换为真实岗位数据源，并补足 100 条 JD、测试集和准确率评估。

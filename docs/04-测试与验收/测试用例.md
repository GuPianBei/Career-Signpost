# 测试用例｜MVP

## 1. 岗位导入测试
输入：10 条岗位 JD 样例。  
预期：系统能成功导入，岗位列表正常展示。

## 2. 技能抽取测试
输入：包含 Java、Spring Boot、MySQL 的 JD。  
预期：技能标签中出现 Java、Spring Boot、MySQL。

## 3. 学生能力输入测试
输入：学生技能为 Java、MySQL、HTML。  
预期：学生画像保存成功。

## 4. 人岗匹配测试
输入：学生 A + Java 后端岗位。  
预期：输出匹配分、匹配技能、缺失技能。

## 5. 推荐测试
输入：缺失技能 Spring Boot、Redis。  
预期：推荐相关课程和实训任务。

## 6. AI 失败兜底测试
场景：关闭 AI API 或模拟失败。  
预期：系统使用模板生成建议，前端不白屏。

## 7. 演示流程测试
目标：3-5 分钟跑完整个流程。  
预期：无明显卡顿、无主流程中断。

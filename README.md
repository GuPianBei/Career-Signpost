# 职向标｜赛题参考版 v2 更新包

本更新包用于把项目从“学生学习路径推荐平台”调整为“岗位能力图谱构建与人岗匹配诊断系统”。

## 使用方式
1. 将本包解压到项目根目录。
2. 将 `docs/02-需求与规格/` 与 `docs/03-技术设计/` 中同名旧文件备份到 `docs/99-归档/历史版本/`。
3. 以 `MVP范围说明-赛题参考版-v2.md` 作为当前开发边界。
4. 以 `技术方案-赛题参考版-v2.docx` 作为当前技术方案主文档。
5. 第一轮只填 10 条岗位 JD 样例，不做 100 条，不做完整参赛指标。

## 本包内容
- MVP范围说明-赛题参考版-v2.md
- 竞品差异分析.md
- 技术方案-赛题参考版-v2.docx
- 技术方案-v2-更新记录.md
- 岗位JD样例数据模板.csv
- 学生能力样例模板.csv
- 课程资源模板.csv
- 实训任务模板.csv

## 当前版本结论
项目采用“转型”策略：不做严格参赛版，不对标招聘平台做投递交易，而是定位为招聘平台前置的能力诊断与学习路径建议工具。
